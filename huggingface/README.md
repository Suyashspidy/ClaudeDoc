# ClaudeDoc — AI Document Quality Assurance Agent

Upload any scanned PDF or image and get an instant AI-powered quality report.

## Features
- Missing page detection
- Folded corner detection
- Blank page detection
- Scanner artifact detection
- Foreign object detection
- Skew/rotation detection
- AI narrative report (Claude)
